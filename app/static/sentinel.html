Sensor telemetry

Compare field measurements with the soil-state model. No water-saving or yield claims are inferred from these readings.

Simulation creates clearly labelled demo readings from the plot model. Real telemetry is accepted from a calibrated ESP32 device; simulated values never control the pump.

Connect a real sensor

1. Register the device and measured moisture calibration points using POST /twin/plots/{plot_id}/sensor-calibration. 2. Save the returned device token securely on the ESP32. 3. Send JSON readings to POST /twin/device/readings with the X-Sensor-Token header. Include a timezone-aware timestamp, increasing sequence number, raw ADC, and optional temperature/humidity.

For durable separate telemetry storage, run the Sentinel SQL section from supabase/schema.sql in Supabase SQL Editor. Until then, readings are retained in the plot state where supported.
